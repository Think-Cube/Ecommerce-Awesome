# Contributing to Awesome E-commerce

Thank you for helping grow this list!

## How to Contribute

### Reporting Issues

Use GitHub Issues to:
- Report a broken or outdated link
- Suggest a tool that should be removed (abandoned, deprecated)
- Suggest a new tool or resource

### Proposing Changes

1. Fork this repository
2. Create a feature branch: `git checkout -b add/tool-name`
3. Make your changes
4. Submit a Pull Request using the provided template

### Guidelines

- Each entry must be a tool, library, or resource directly useful for e-commerce operations
- Link to the official website or GitHub repository — not a blog post or affiliate link
- Description format: start with a lowercase letter, end with a period, max ~120 characters
- Use the existing entry style: `* [Name](url) – description.`
- Add new entries in alphabetical order within their section
- The tool must be actively maintained (last release or commit within the past 2 years)
- Do not add self-promotional links or paid-only tools without a meaningful free tier
